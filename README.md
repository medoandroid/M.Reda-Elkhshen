## نبذة عن المشروع
موقع تعريفي فاخر مبني بأحدث معايير الواجهات الرقمية العالمية (Modern Parisian Academic Luxury)، ومخصص لعرض خبرة الأستاذ **رضا الخشن** الممتدة لأكثر من 10 سنوات في تدريس اللغة الفرنسية لطلاب المدارس الدولية، مدارس اللغات، المدارس الحكومية، ونظام البكالوريا (Baccalauréat).

## البنية الهندسية
- **النوع:** Static Single Page Application (HTML5, Modern CSS3 Variables & Flex/Grid, ES6+ Vanilla JS).
- **الاعتماديات:** صفر تبعيات معقدة (Zero-dependency)، أداء فائق 60fps وسرعة تحميل لحظية على أجهزة الهواتف المحمولة ومتصفحات أندرويد.
- **التصميم:** يدعم الاتجاه العربي بالكامل (RTL) مع ضبط دقيق للرموز والمصطلحات والروابط الفرنسية (LTR)، متجاوب بدقة مع شاشات الهواتف (360px - 390px)، الشاشات المتوسطة والأجهزة اللوحية (768px - 992px) وشاشات سطح المكتب.

## التشغيل والاختبار
لتشغيل المشروع محلياً:
```bash
# خيار 1: فتح مباشر في المتصفح
double-click index.html

# خيار 2: عبر خادم محلي باستخدام Node.js
npm run dev

# خيار 3: عبر خادم بايثون السريع
python -m http.server 3000
```

لإجراء الاختبارات الآلية للتحقق من سلامة الأصول والروابط:
```bash
node test/verify.js
```
