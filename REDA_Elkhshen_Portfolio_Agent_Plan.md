# الجزء الرابع: خطة التنفيذ الإلزامية

## 7. المرحلة صفر --- الفحص الشامل قبل أي تعديل

هذه المرحلة إلزامية، وهي أول ما يجب تنفيذه.

1.  افحص كل الملفات والمجلدات داخل Workspace بشكل recursive، مع احترام
    صلاحيات الوصول.
2.  اعرض شجرة الملفات، وحدد الملفات المخفية والملفات المهمة.
3.  افحص امتدادات الملفات وأحجامها وأنواعها.
4.  ابحث عن الصور والشعارات ولقطات الشاشة وملفات PDF والمستندات وملفات
    التصميم ومقاطع الفيديو.
5.  افتح الصور المهمة بصريا، ولا تعتمد على أسماء الملفات فقط.
6.  افحص ملفات الكود وملفات الإعدادات وملفات package/dependency وملفات
    README.
7.  افحص أي موقع أو مشروع قائم لتحديد ما يمكن إعادة استخدامه.
8.  افحص الروابط الخارجية المقدمة عند توفر اتصال آمن، وسجل نتيجة كل
    رابط.
9.  لا ترفع الملفات الخاصة إلى خدمات خارجية.
10. لا تحذف أو تنقل أو تعيد تسمية أي ملف في مرحلة الفحص.
11. لا تبدأ تثبيت dependencies أو تعديل المشروع قبل كتابة تقرير الفحص.
12. عند وجود ملفات ضخمة أو غير قابلة للقراءة، سجلها بوضوح ولا تدّع فحص
    محتواها.

أما المعلومات الشخصية والمهارات المقترحة فتظل غير منشورة حتى اعتمادها.
